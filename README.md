# ✨ Quote Generator

**A beautiful single-file random quote generator with categories, copy-to-clipboard, and dark mode.**

Day 12 (simple build) of my daily coding journey — two projects shipped every day.

## Features
- 📚 12 hand-picked quotes across 4 categories (Motivation, Wisdom, Hustle, Coding)
- 🎲 Random quote with a new one every time — never repeats twice in a row
- 📋 One-click **copy to clipboard**
- 🌙 Dark / light mode toggle
- ⌨️ Press **Space** for a new quote
- 💯 Zero dependencies — just one HTML file

## Run it in 30 seconds
Just open `index.html` in any browser. That's it.

## What I practiced
- DOM selection and event listeners
- Filtering arrays by category
- Clipboard API (`navigator.clipboard`)
- CSS variables for theming
- Keyboard event handling
